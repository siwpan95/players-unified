# 日常视频播放器 (Daily Player)

基于 VLC 的日常视频播放器，支持字幕、播放列表和快捷键。

## 功能

- **视频播放** — 基于 python-vlc，支持 mp4/avi/mkv/mov/wmv/flv/webm/m4v
- **SRT 字幕** — 自动解析同目录 .srt 文件，实时显示字幕
- **内嵌字幕** — 支持切换 VLC 内嵌字幕轨道
- **播放列表** — 添加文件/文件夹，双击切换，Delete 删除
- **进度条** — 拖拽跳转，实时时间显示
- **播放速度** — 0.25x ~ 3.0x 可调
- **快进快退** — +/-10 秒跳转
- **截图** — 视频瞬间截图保存为 PNG
- **全屏** — 双击视频区域或 F11 切换
- **音量控制** — 滑块 + 鼠标滚轮
- **主题切换** — 深色 / 浅色主题 (T 键切换)
- **系统托盘** — 最小化到系统托盘 (需 pystray)
- **配置记忆** — 自动记住音量、窗口大小、播放位置
- **快捷键** — 空格暂停、左右键快进快退、上下键音量、F 全屏、T 主题

## 快速开始

```bash
# 安装依赖
pip install python-vlc

# 安装 VLC 播放器 (必需)
# https://www.videolan.org/vlc/

# 可选：系统托盘支持
pip install pystray Pillow

# 启动
python play.py
```

## 快捷键

| 按键 | 功能 |
|------|------|
| 空格 | 播放 / 暂停 |
| ← → | 后退 / 前进 10 秒 |
| ↑ ↓ | 音量加减 |
| F / F11 | 全屏切换 |
| T | 主题切换 |
| Enter | 全屏 |
| Esc | 退出全屏 |
| 鼠标滚轮 | 调节音量 |
| 双击视频 | 全屏切换 |

## 依赖

- Python >= 3.8
- python-vlc >= 3.0
- VLC 播放器 (外部)
- pystray, Pillow (可选，系统托盘)
